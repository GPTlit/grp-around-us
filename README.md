# Card Whisperer

A group chat game, very clean and nice style and bright (dark mode and light mode) 3 players, one is the moderator of the game, he has cards like ❤️♦️♣️♠️ all 32 cards 

We get cards from the moderator 

We get to ask 10 queations about it, and we can lie 3 times if we are being asked

Features (which are buttons you click to infrom the moderator you wanna use that feature)

 Loan  for asking the operator if he lied or not

Repeat for repeating questions 

And stop for stopping the guy if he lied more than 3 times and you win, but if not, You lose your stop and the only way to win is figure out his card, same as any other feature like loan and repeat, you use them one time
